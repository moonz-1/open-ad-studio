# Contributing

Thank you for interest in Open Ad Studio.

1. Use Node.js 22.18+.
2. `npm ci` then `npm run typecheck` / `npm run test:release` before PRs.
3. Never commit `.env`, API keys, SSH material, customer media, or model weights.
4. Prefer small, reviewed changes with Conventional Commit messages.
5. Document new models in `docs/MODELS_AND_LICENSES.md` with license + source URL.
