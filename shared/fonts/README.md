# Bundled advertisement fonts (OFL)

These files are used by Resvg exports and Graphic Art Director SVG. All are SIL Open Font License.

| File | Family | License source |
|------|--------|----------------|
| `EBGaramond-Regular.ttf` | EB Garamond | Google Fonts / OFL |
| `Newsreader-Regular.ttf` | Newsreader | Google Fonts / OFL |
| `SourceSans3-Regular.ttf` / `SourceSans3-Semibold.ttf` | Source Sans 3 | Adobe / OFL |
| `DMSans-Medium.ttf` | DM Sans | Google Fonts / OFL |
| `Outfit-SemiBold.ttf` | Outfit | Google Fonts / OFL |

Do not substitute unlicensed commercial faces. Browser preview may fall back to system stacks with the same family names.

Copyright and complete OFL notices are retained in [licenses](licenses/). Sources: [ebgaramond](https://github.com/google/fonts/tree/main/ofl/ebgaramond), [newsreader](https://github.com/google/fonts/tree/main/ofl/newsreader), [sourcesans3](https://github.com/google/fonts/tree/main/ofl/sourcesans3), [dmsans](https://github.com/google/fonts/tree/main/ofl/dmsans), [outfit](https://github.com/google/fonts/tree/main/ofl/outfit). The browser copies have the same font bytes. `public/OFL-font-licenses.txt` also ships the notices in the production build.
